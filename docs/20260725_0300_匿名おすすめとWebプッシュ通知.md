# 匿名おすすめとWebプッシュ通知

作成日: 2026-07-25

## 目的

ログインや個人情報の登録を求めず、利用者が選んだ3つの小分類から、未表示の公開案件を1日最大5件おすすめする。希望者には同じ日別推薦を毎朝1回だけWebプッシュ通知する。

## 既存構成

- Next.js 15 App Router / React 19
- Supabase PostgreSQL / Supabase JS
- トップページ: `web/src/app/(main)/page.tsx`
- 案件: `bills`、本文: `bill_contents`、タグ: `tags` と `bills_tags`
- 公開条件: `bills.publish_status = 'published'`
- PWA manifestとアイコンは既存。Service Worker、Web Push、Cron、一般API用レート制限は今回追加

## データモデル

マイグレーション: `20260725120000_create_recommendation_and_push_tables.sql`

- `recommendation_profiles`: installation UUID、3タグ、親分類、timezone、設定版
- `daily_recommendations`: profile・JST日付・設定版ごとの最大5件と推薦種別
- `recommendation_impressions`: profile・billを一意にした初回表示履歴
- `push_subscriptions`: endpoint、暗号鍵、有効状態、通知日、試行状態
- `recommendation_api_rate_limits`: HMAC化した短期キーと固定窓カウント

全テーブルはRLS有効、ポリシーなし。WebアプリのService Role経由だけでアクセスする。

DB関数:

- `save_recommendation_preferences`
- `reset_recommendation_history`
- `save_push_subscription`
- `claim_daily_push_subscriptions`
- `consume_recommendation_rate_limit`

## 推薦処理

共通入口は `getOrCreateDailyRecommendations(profileId, date)`。

1. 選択した3タグから原則1件ずつ
2. 選択タグの残りで小分類枠を最大3件まで補完
3. 親大分類内の未選択タグから補完
4. 親大分類内の全タグから補完

公開済み、normal本文あり、正規タグあり、未表示の案件だけを対象にする。無関係な分類は混ぜない。profile・日付・設定版をseedにした決定的順序で選び、同日の再訪では保存済みIDを返す。一意制約競合時は先に作られた日別レコードを読み直す。

## API

- `PUT /api/recommendations/preferences`
- `POST /api/recommendations/today`
- `POST /api/recommendations/impressions`
- `POST /api/recommendations/reset-history`
- `DELETE /api/recommendations/profile`
- `POST /api/push/subscribe`
- `POST /api/push/unsubscribe`
- `GET /api/cron/daily-recommendations`

匿名IDはJSON本文だけで渡す。公開APIは16KB上限、Zod検証、同一Origin必須、installation IDと短期HMAC化IPの二重レート制限を適用する。HMACキーは時間窓ごとに変え、レート制限行は2日後に削除する。Raw IP、User-Agent、購読鍵、秘密値をログへ残さない。

Push購読endpointは、FCM、Mozilla Push Service、Apple Web Push、Windows Notification ServiceのHTTPSホストだけを許可する。任意の外部URLをCronから呼び出せないようにする。

## Web Push

- Service Worker: `web/public/sw.js`
- Cron: 毎日 `23:00 UTC`、JST `08:00`
- 通知クリック先: `/#today-recommendations` 固定
- tag: `daily-recommendations-YYYY-MM-DD`
- 成功時のみ一件目をpush表示履歴へ保存
- 404/410は購読を失効、その他の失敗は同日再送しない

通知権限は利用者がボタンを押したときだけ要求する。通知非対応・拒否・登録失敗でもサイト内おすすめは維持する。iPhone/iPadはホーム画面へ追加したWebアプリでのみWeb Pushを利用できる。

Vercel HobbyではCronが指定時刻の1時間内に実行される場合がある。8:00ちょうどが必要ならProまたは外部スケジューラを使う。
