## 結論

- 公式歳入CSVはBOMなしの`CP932`である。`UTF-8`と厳密な
  `Shift_JIS`ではデコードできないため、`CP932`で読む。
- CSVは52列、論理データ18,930行である。令和8年度・当初は
  指定どおり2,192行で、5会計の行数と現計予算額がすべて一致した。
- 令和8年度・当初の全2,192行で、
  `現計予算額 = 現計充当額 + 現計未充当額`が成立した。
- `会計 + 款 + 項 + 目 + 節 + 細節 + 所属`は2,192行すべてで一意で
  ある。`歳入番号`をキーへ追加する必要はない。
- PDFの歳入範囲は4つのactive会計について実ファイルから確定した。
  学校給食費会計は`abolished_zero`であり、PDF抽出対象外とする。
- PDFでは1細節に0件、1件、複数件の充当事業があり得る。充当事業が
  次のPDF物理ページへ続く例もあるため、将来の抽出器はstatefulにする。
- このPhaseでは`processed/`配下のCSV、JSON、PDF抽出CSVを作成・変更
  していない。

### 歳入番号を追加した確認

比較のため次の8列でも確認した。

```text
会計 + 款 + 項 + 目 + 節 + 細節 + 所属 + 歳入番号
```

こちらも2,192行すべてで一意だが、7列の時点で一意なため、
`歳入番号`を一意性のための追加キーにはしない。`歳入番号`と
`歳入番号名称`は公式原値および出典追跡用の属性として保持する。

なお、`所属`を除くと同じ階層コードを複数部署が持つ可能性があるため、
将来の正規化で`所属`を落としてはならない。

### 表形式

4会計とも基本レイアウトは共通している。

- 左側: 款・項・目、本年度、前年度、比較
- 右側: 節コード、節名称、節金額、説明
- 説明欄: 細節コード、細節名称、担当部、細節金額

抽出テキストでは、節名称や長い事業名が改行される。`･P000`の前に空白や
改行が入る例もあるため、1行だけを正規表現で処理してはならない。

## 設計の固定

### configの扱い

既存の`config/budget-accounts.json`のトップレベル会計項目は歳出用設定として
そのまま保持し、各会計の末尾へ`revenue`を追加した。既存キーの名称、値、
並び順は変更していない。

active会計:

```json
{
  "revenue": {
    "expected_amount_thousand_yen": 431353010,
    "pdf_budget_book_start_page": 67,
    "pdf_budget_book_end_page": 307,
    "pdf_page_start": 37,
    "pdf_page_end": 157,
    "status": "active"
  }
}
```

廃止0円会計:

```json
{
  "revenue": {
    "status": "abolished_zero"
  }
}
```

将来の歳入抽出処理は、トップレベルの歳出PDF範囲ではなく、必ず
`account.revenue`の範囲と状態を参照する。

### 将来の正規化単位

- CSV歳入明細の正本単位は
  `会計・款・項・目・節・細節・所属`とする。
- `歳入番号`と`歳入番号名称`は公式原値として保持するが、一意キーの
  tie-breakerにはしない。
- PDFの充当事業は、細節にぶら下がる0件以上の子要素として扱う。
- 1細節から複数の充当事業への関係を許容する。
- 充当事業名と冊子ページだけで`program_id`へ自動結合しない。
  事業名、会計、金額、冊子ページ、公式CSVの事業階層を使った照合と
  検証が完了してから関係テーブルを作る。
- `充当`は当初予算上の財源充当であり、実支出、決算、契約、支払先を
  示すものではない。
- 一般会計の未充当額を、個別事業の一般財源額へ機械的に配賦しない。

### PDF抽出器に必要な状態

将来の全ページ抽出器は少なくとも次をページ間で保持する。

```text
current_account
current_kan
current_kou
current_moku
current_setsu
current_saisetsu
current_allocation_target
```

ページ冒頭が`充当事業：`で始まる場合は、直前ページの
`current_saisetsu`へ追加する。新しい細節、節、目、項、款、会計を検出した
時点で直前状態を閉じる。
