## 結論

- CSVはBOMなしのShift_JIS系で、`CP932` と `Shift_JIS` のどちらでも厳密に
  デコードできる。Windows由来のCSVとして、今後は `CP932` で読むのが安全で
  ある。
- CSVはヘッダー1行とデータ10,250行、全97列で、全レコードの列数が一致する。
- 指定された年度、会計、款・項・目、各事業階層、3つの金額列はすべて存在する。
- PDFは全408ページにテキスト層があり、OCRなしでテキストを抽出できる。
- 歳出のサンプルページでは、「節」の区分・金額を3列の表として抽出できた。
  ただし、複数の「目」が同じページに載る場合は、座標または罫線を使って各節の
  所属先を復元する必要がある。

### 金額列の注意点

- `予算見積額` は1,170件中1,050件に桁区切りカンマが入っている。
- `充当額` と `一般財源額` には桁区切りカンマが入っていない。
- 3列とも、カンマを除去すると全件が符号付き整数として解釈できる。
- `一般財源額` には負数があり、2026年度の最小値は `-3,267,254` である。
- 2026年度の全1,170行で、
  `予算見積額 = 充当額 + 一般財源額` が成立した。

金額中のカンマはCSV上では引用符で保護されている。単純な文字列分割ではなく、
CSVパーサーで読む必要がある。

## 歳出「節」欄のサンプル確認

一般会計の歳出はPDF 158ページ目の区切りページから始まり、PDF 159ページ目に
最初の歳出明細がある。PDFの1ページは冊子の2ページ分を含む。

### サンプル1: PDF 159ページ目（冊子310-311ページ）

- 対象: 款01 議会費、項01 議会費、目01 議会費
- 右側の表を `節区分`、`金額`、`説明` の3列として抽出できた。
- 実データとして10件の節を取得できた。
- 例: `01 報酬 / 600,135`、`18 負担金補助及交付金 / 3,137`
- 10件の節金額合計は `770,553` で、目の本年度額 `770,553` と一致した。

### サンプル2: PDF 166ページ目（冊子324-325ページ）

同じページに複数の目が掲載されるケースも確認した。

| 目 | 抽出できた節数 | 節金額合計 | 目の本年度額 |
| --- | ---: | ---: | ---: |
| 01 税務総務費 | 5 | 2,182 | 2,182 |
| 02 賦課徴収費 | 8 | 1,379,576 | 1,379,576 |

表抽出自体は成功し、節金額の合計もそれぞれ一致した。一方、一般的な表抽出では
右側の節表が1つの表に結合されるため、どの節がどの目に属するかは、左側の
目の枠と右側の節行の縦座標を使って分割する必要がある。

### 抽出時に考慮が必要な点

- PDFページ番号と冊子のページ番号は一致しない。
- 1つのPDFページに冊子2ページ分が収録され、節表は主に右半分にある。
- `使用料及賃\n借料` のように、節名称が複数行に分かれる。
- ページによって複数の目が1つの節表内に連続して現れ、節コードも繰り返される。
- ヘッダー行や空行が表の抽出結果に含まれる。
- 説明欄の複数行が、表抽出結果では先頭の節行にまとまる場合がある。
- タグ付きPDFではないため、階層の復元には文字列だけでなく座標・罫線情報が
  必要になる。

以上から、「節」の区分と金額は抽出可能と判断する。ただし全ページを対象にした
抽出精度、ページまたぎ、複数の目への所属判定はまだ検証していない。
